# Placoro_diceroller
## キャラコロ・エネコロ　ダイスローラー
webアプリで開く場合は[こちら](https://chickenmaycry.github.io/Placoro_diceroller/)をクリック

Safari画面下部の 共有アイコン（四角に上矢印） をタップします。
メニューから 「ホーム画面に追加」 を選択すると、スタンドアロンアプリとしてiPhone上で動作します。 アップデートによってアプリ内容の変更があった場合、再度同様の手順が必要です。

プラコロ　対戦サポートツールは[こちら](https://github.com/ChickenMayCry/Placoro_support.io)
